Density-Based Adaptive Traffic Signal System

A camera-based concept that adjusts green time according to traffic density and the number of waiting vehicles.

Context

MTech HSE academic project

Problem

Fixed signal timings can give lightly used lanes the same green time as congested ones. The project explored whether adaptive timings could use that time more effectively.

Design concept

I designed a four-lane concept that uses camera observations to estimate traffic density and count waiting vehicles. The controller would allocate green time dynamically using those inputs.

Intended outcome

The design aims to limit unnecessary green time for lightly used lanes and better serve longer queues. Reduced signal violations were a design objective that would require field testing to evaluate.
